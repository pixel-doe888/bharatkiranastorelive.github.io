📡 OBS Streaming Setup

This website is designed to display a live HLS stream. To stream from OBS, connect OBS to an RTMP streaming server or streaming provider. The server then converts your OBS stream into an HLS stream that this website can play.

OBS Stream Server rtmp://YOUR-STREAM-SERVER/live
Stream Key YOUR-PRIVATE-STREAM-KEY
Website Stream URL https://YOUR-DOMAIN.com/live/stream.m3u8
Recommended OBS Settings H.264 • AAC • 1080p • 30 FPS
